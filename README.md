Solmar Bay is a complete open-world crime game in the sun: explore a fictional coastal city on foot and by car, steal vehicles, outrun the police across five wanted levels, and play through an 8-mission story with combat, taxi fares, hidden packages and a living minimap.

Controls: WASD walk/drive, E enter & steal cars, mouse aim + click shoot, F punch, T taxi fare, C save, N restart mission, P pause, M mute.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under `game/`.
